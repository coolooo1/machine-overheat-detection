# 專案完整性驗證

驗證日期：2026-10-07（台北時間）。驗證範圍為目前的 C17 設備控制模擬與 CSV 紀錄版本。

## 結論

目前版本可以從原始碼編譯、執行互動流程並產生 CSV。控制模組、紀錄模組與主程式的整合流程通過下列檢查，未發現阻止此模擬專案展示的錯誤。

這份報告是特定版本與情境的驗證結果，不代表所有可能的輸入、作業系統或儲存裝置都已驗證。

## 環境與編譯

- Windows，GCC 14.2.0（MSYS2 UCRT64）。
- PowerShell 7 與 Windows PowerShell 5.1 的一鍵編譯及全部測試均實際通過。腳本採 UTF-8 BOM，避免舊版 PowerShell 誤讀中文註解。
- 使用 C17，編譯參數包含 `-Wall -Wextra -Wpedantic -Werror -g`。
- 正式程式、兩個單元測試程式與失敗注入程式均編譯成功，沒有編譯警告。
- 原始教學版本先通過 30 項單元檢查與 6 個整合情境，再整理成此專案。
- GitHub 版本以 `scripts/build.ps1 -Test` 執行相同單元測試，並擴充至 18 個整合情境。

## 驗證方式

控制測試包含門檻邊界和故障復原規則。紀錄測試讀回暫存檔，對照預期列文字。整合測試以獨立程序執行 CLI，在每個情境的獨立工作目錄檢查 CSV、退出碼和輸出。

寫入失敗情境使用測試替身，確認主程式收到失敗回傳值後的處理。沒有實際塞滿硬碟、拔除裝置或破壞使用者的紀錄檔案。

## 本次未涵蓋

- 真實馬達、感測器、硬體輸出回饋或即時排程。
- 大型檔案、程序並行寫入、突然斷電和作業系統層的儲存耐久性。
- 所有 `fseek()`、`ftell()`、`fprintf()`、`fflush()`、`fclose()` 底層錯誤的個別注入。
- 每一列既有 CSV 的完整內容驗證；目前只檢查標頭及結尾換行。
- GitHub 雲端工作流程實際執行。已提供 Windows CI 設定，上傳後應查看 Actions 結果。
